# byo-alien

The byo-alien project's goal is to provide an easy-to-use library that helps developers create Bring Your Own Key (BYOK) applications on top of LLMs. As it is in its earliest stages of creation, it currently has more hopes and dreams than tangible deliverables. The aforementioned hopes and dreams are:

### Hopes
- support OpenAI, Anthropic, and Google APIs (the OpenAI API also covers other models and providers that support it)
- basic key management and token usage statistics
- model management/switching
- local conversation management
- local MCP
- local RAG

### Dreams
- Swift package available via Swift Package Manager
- Kotlin library published to Maven Central (usable from Gradle)
- JavaScript/TypeScript package available via npm
- Rust crate available via crates.io

## Who Is This For?
This would be for developers who want to build applications on top of LLM technology and are interested in serving an admittedly niche user: someone who has an LLM key and isn't afraid to use it. The hope is to introduce apps with a simplified business model where the cost of the LLM is more transparent.
